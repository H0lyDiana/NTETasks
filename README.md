# 异环 · 都市手账

《异环》日常任务清单，纯静态网页，**无需安装、无需联网**，双击 `index.html` 就能用。

> 线上版：<https://h0lydiana.github.io/NTETasks/>
>
> 纯前端站点，也可自行部署到任意静态托管。

## 功能

- **四类任务**：每日 / 每周 / 特殊 / 每月，外加「所有」汇总视图；侧栏实时显示各类完成数
- **到点自动重置**：每日 05:00、每周一 05:00、每月 1 日 00:00（北京时间）；「特殊」任务按自己的开始时间与间隔天数各自结算
- **已完成自动沉底**：未完成在上、已完成在下，勾选后立即归位
- **倒计时**：显示距下次重置还有多久
- **版本日历**：1.1 ~ 1.4 当期活动长图，折叠展开，图片懒加载
- **羁遇赠礼**：V1.4 全部 22 位角色的赠礼速查，含好感经验表与速升 / 省钱 / 均衡三路线计算，可按等级与好感度算所需礼物与方斯
- **一咖舍**：内嵌的经营收益计算器，直接在手账里算
- **深浅色主题**：橙色 / 黄绿色两套配色，跟随按钮切换
- **进度环**：当前分类完成比例一眼可见

### 可选机制（需在任务数据里配置才生效）

| 字段 | 作用 |
| --- | --- |
| `minor: true` | 次要任务：排在已完成之后，不计入总数 |
| `clock` | 勾选完成 N 小时后自动重置 |
| `earn` | 填写每小时收益，累计满整小时自动重置 |
| `countStep` | 每完成一次计数累加 |
| `link: [id, …]` | 关联任务：主任务完成时，从属任务一起完成；主任务重置时从属一起重置 |

## 目录结构

```
index.html            页面骨架
assets/
  style.css           样式与主题
  data.js             全部任务数据（window.NTE_DATA）
  app.js              渲染、计时、存档逻辑
cloud/
  cloud-config.js     云存档配置（默认留空 = 纯本机模式）
  cloud.js            云存档客户端
images/
  1.1.jpg ~ 1.4.jpg   版本日历长图
bond/
  index.html          羁遇赠礼速查页（以 iframe 相对嵌入）
  assets/             该页自己的 css / js / 图片
```

## 本地使用

直接双击 `index.html`。进度保存在浏览器 `localStorage`，换浏览器或清缓存会重置。

## 修改任务

任务都在 `assets/data.js` 的 `window.NTE_DATA` 里：`categories` 定义分类，`tasks` 是任务数组，改完刷新页面即可。

## 云存档

仓库里的 `cloud/cloud-config.js` 中 `endpoint` 与 `envId` 是空的，因此**默认不启用云存档**，纯本机运行。若要跨设备同步，需要自建 CloudBase 环境（PostgreSQL + 云函数 `nte-api`，提供登录 / 读取 / 保存三个接口），再把地址填进该文件。
